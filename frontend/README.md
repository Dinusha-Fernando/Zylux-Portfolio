# ⚡ Zylux Web Application (Frontend)

> **Next.js 16 Production Web Application for Zylux Software Solutions**  
> High-performance digital engineering, cybersecurity architecture, and digital growth systems. Founded by **W.M. Dinusha Kalhara Fernando**.

---

## 🛠️ Technology Stack

- **Framework**: Next.js 16.3.5 (App Router, Turbopack, React Server Components)
- **Runtime & UI**: React 19, TypeScript 5.x
- **Styling**: Tailwind CSS 3.4, Vanilla CSS Design Tokens, CSS Backdrop Blurs
- **Icons**: Lucide React
- **Typography**: Google Fonts (Inter, Plus Jakarta Sans)
- **Deployment**: Node.js SSG / Vercel Edge

---

## 📂 Frontend Directory Architecture

```
frontend/
├── public/assets/            # Production image assets, logos, and backdrops
├── src/
│   ├── app/                  # App Router: Pages & static routes
│   │   ├── about/            # Studio identity, founder profile & values
│   │   ├── contact/          # Direct architecture desk & intake form
│   │   ├── insights/         # Engineering publications & case insights
│   │   ├── process/          # 4-step delivery methodology
│   │   ├── services/         # 14 specialized service discipline routes
│   │   ├── solutions/        # Technology and digital solution hubs
│   │   ├── work/             # Production portfolio case studies
│   │   └── globals.css       # Design tokens, theme variables & animations
│   ├── components/           # Reusable UI component library
│   │   ├── home/             # Homepage sections (Hero, ClientStrip, SelectedWork, etc.)
│   │   ├── layout/           # Navbar, Footer, GlobalAtmosphere
│   │   └── ui/               # Button, Badge, CreativeBackground, Motion
│   ├── context/              # Global theme context (Dark/Light sync)
│   ├── data/                 # Strongly-typed data definitions
│   ├── lib/                  # Utilities (cn, formatters)
│   └── types/                # Core TypeScript interfaces
├── package.json              # Dependencies and npm scripts
├── tsconfig.json             # TypeScript path mappings & compiler options
└── next.config.ts            # Next.js configuration
```

## ⚡ Running Locally

From inside the `frontend` folder:

```bash
# 1. Install dependencies
npm install

# 2. Run local development server (with Turbopack)
npm run dev

# 3. Build for production (SSG static site export validation)
npm run build

# 4. Start production server
npm run start
```
